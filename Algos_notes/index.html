01

Bubble Sort

Easy
O(n²)
📖 Definition

Repeatedly compares adjacent elements and swaps them if out of order. Largest element "bubbles up" to end in each pass. Like sorting by repeatedly picking bubble to top!

📐 Key Facts
  • Passes needed = n − 1
  • Comparisons in pass i = n − i
  • Max swaps = n(n−1)/2
  • Optimization: stop if no swap in a pass
⚡ Complexity
CaseTimeSpace
BestO(n)O(1)
AverageO(n²)
WorstO(n²)
✓ Stable ✓ In-Place
🔢 Numerical — Sort [29, 10, 14, 37, 13]
C++ Code
void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n-1; i++) {
        bool swapped = false;
        for (int j = 0; j < n-i-1; j++) {
            if (arr[j] > arr[j+1]) {
                swap(arr[j], arr[j+1]);
                swapped = true;
            }
        }
        if (!swapped) break; // Already sorted!
    }
}
💡 Key Points to Remember
  • Best case O(n) when array already sorted (with flag check)
  • Called "Bubble" — larger elements bubble to the top each pass
  • Total passes = n-1, comparisons in pass i = n-i-1
  • Rarely used in practice — only for educational purposes

Selection Sort

Easy
O(n²)
📖 Definition

Divides array into sorted and unsorted parts. Finds minimum from unsorted part and places it at the beginning of unsorted. Repeats until fully sorted.

⚡ Complexity
CaseTime
Best/Avg/WorstO(n²)
SpaceO(1)
✗ Unstable ✓ In-Place
🔢 Numerical — Sort [64, 25, 12, 22, 11]
C++ Code
void selectionSort(int arr[], int n) {
    for (int i = 0; i < n-1; i++) {
        int minIdx = i;
        for (int j = i+1; j < n; j++)
            if (arr[j] < arr[minIdx]) minIdx = j;
        swap(arr[minIdx], arr[i]);  // Always n-1 swaps
    }
}
💡 Key Points
  • Always makes exactly n-1 swaps — great when write operations are costly
  • Unstable: equal elements may change relative order
  • Total comparisons = n(n-1)/2 regardless of input

Merge Sort

Medium
O(n log n)
📖 Definition

Divide and Conquer: Recursively split array in halves until single elements. Then merge sorted halves back. Guaranteed O(n log n) always.

📐 Recurrence
T(n) = 2T(n/2) + O(n)
→ By Master Theorem: O(n log n)
⚡ Complexity
CaseTimeSpace
BestO(n log n)O(n)
AverageO(n log n)
WorstO(n log n)
✓ Stable ✗ Extra Space
🔢 Numerical — Sort [38, 27, 43, 3, 9, 82, 10]
C++ Code
void merge(int arr[], int l, int m, int r) {
    vector<int> L(arr+l, arr+m+1), R(arr+m+1, arr+r+1);
    int i=0, j=0, k=l;
    while(i<L.size() && j<R.size())
        arr[k++] = (L[i]<=R[j]) ? L[i++] : R[j++];
    while(i<L.size()) arr[k++]=L[i++];
    while(j<R.size()) arr[k++]=R[j++];
}
void mergeSort(int arr[], int l, int r) {
    if(l < r) {
        int m = l + (r-l)/2;
        mergeSort(arr, l, m);
        mergeSort(arr, m+1, r);
        merge(arr, l, m, r);
    }
}
💡 Key Points
  • Best for linked lists — no random access needed for merge
  • Used in external sorting (when data doesn't fit in RAM)
  • Basis of Timsort (Python/Java's built-in sort)
  • Merge step: compare heads, take smaller — O(n) per level

Quick Sort

Medium
O(n log n) avg
📖 Definition

Pick a pivot → Partition array so that elements < pivot are left, elements > pivot are right → Recursively sort both halves. Pivot ends up at its correct final position.

⚡ Complexity
CaseTime
Best/AvgO(n log n)
WorstO(n²)
SpaceO(log n)
✗ Unstable ✓ In-Place ✓ Cache-friendly
🔢 Numerical — Partition step on [10, 80, 30, 90, 40, 50, 70], pivot = 70
C++ Code
int partition(int arr[], int low, int high) {
    int pivot = arr[high], i = low - 1;
    for (int j = low; j < high; j++)
        if (arr[j] <= pivot) swap(arr[++i], arr[j]);
    swap(arr[i+1], arr[high]);
    return i + 1;  // pivot's final index
}
void quickSort(int arr[], int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quickSort(arr, low, pi-1);   // left of pivot
        quickSort(arr, pi+1, high);  // right of pivot
    }
}
💡 Key Points
  • Worst case O(n²) when pivot is always min/max — use random pivot to avoid
  • Fastest in practice due to cache locality
  • C++ std::sort uses Introsort = Quick + Heap + Insertion

Dijkstra's Algorithm

Medium
O((V+E) log V)
📖 Definition

Single Source Shortest Path for graphs with non-negative weights. Uses a Min-Heap (priority queue). Greedily selects nearest unvisited vertex and relaxes its edges.

📐 Relaxation
if dist[u] + w(u,v) < dist[v]:
dist[v] = dist[u] + w(u,v)

⚠️ Fails with negative edges!
⚡ Complexity
ImplementationTime
ArrayO(V²)
Binary HeapO((V+E)logV)
SpaceO(V)
✓ Greedy ✗ No neg edges
🔢 Numerical — Shortest path from node 0
C++ Code (Min-Heap)
void dijkstra(vector<pair<int,int>> adj[], int V, int src) {
    vector<int> dist(V, INT_MAX);
    priority_queue<pair<int,int>,
        vector<pair<int,int>>, greater<>> pq;
    dist[src] = 0;
    pq.push({0, src});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue;  // outdated entry
        for (auto [v, w] : adj[u])
            if (dist[u]+w < dist[v]) {
                dist[v] = dist[u]+w;
                pq.push({dist[v], v});
            }
    }
}

Kruskal's Algorithm (MST)

Medium
O(E log E)
📖 Definition

Finds Minimum Spanning Tree. Sort all edges by weight → Add edges one by one (greedily) → Skip edge if it forms a cycle (checked via Union-Find). Stop when V-1 edges added.

📐 MST Properties
MST has exactly V-1 edges
Connects all V vertices
Minimum total weight
No cycles!
⚡ Complexity
StepTime
Sort edgesO(E log E)
Union-FindO(α(V)) ≈ O(1)
TotalO(E log E)
SpaceO(V)
🔢 Numerical — Find MST of graph (4 vertices)
C++ Code (Union-Find)
int find(int parent[], int i) {
    return parent[i]==i ? i : parent[i]=find(parent,parent[i]);
}
void kruskal(vector<tuple<int,int,int>>& edges, int V) {
    sort(edges.begin(), edges.end()); // sort by weight
    vector<int> parent(V);
    iota(parent.begin(), parent.end(), 0);
    int cost = 0, cnt = 0;
    for (auto [w, u, v] : edges) {
        int pu=find(parent.data(),u), pv=find(parent.data(),v);
        if (pu != pv) {   // no cycle!
            parent[pu] = pv;
            cost += w; cnt++;
            if (cnt == V-1) break;
        }
    }
    cout << "MST Cost = " << cost;
}

Huffman Coding

Hard
O(n log n)
📖 Definition

Lossless data compression using greedy approach. Assigns shorter binary codes to more frequent characters. Build a min-heap tree bottom-up.

📐 Key Rules
  • Left child → 0, Right child → 1
  • Always merge 2 nodes with lowest freq
  • Result: Prefix-free codes
  • No code is prefix of another
⚡ Complexity
StepTime
Build heapO(n)
Build treeO(n log n)
SpaceO(n)
✓ Lossless ✓ Optimal prefix
Used in: ZIP, JPEG, MP3, PNG
🔢 Numerical — Characters: a(5), b(9), c(12), d(13), e(16), f(45)
