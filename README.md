# C++ Algorithms Collection

A collection of core algorithms implemented in C++, categorized by domain:

## 📁 Repository Structure

### 🔹 Graph Algorithms (`/graph_algorithms`)
- `1_dijkstra.cpp` - Dijkstra's Shortest Path Algorithm
- `2_prims.cpp` - Prim's Minimum Spanning Tree (MST) Algorithm
- `3_kruskals.cpp` - Kruskal's Minimum Spanning Tree (MST) Algorithm

### 🔹 Greedy Algorithms (`/greedy_algorithms`)
- `1_fractional_knapsack.cpp` - Fractional Knapsack Problem
- `2_job_sequencing.cpp` - Job Sequencing with Deadlines
- `3_huffman_coding.cpp` - Huffman Coding Compression
- `4_optimal_merge_pattern.cpp` - Optimal Merge Pattern

### 🔹 Sorting Algorithms (`/sorting_algorithms`)
- `1_bubble_sort.cpp` - Bubble Sort
- `2_insertion_sort.cpp` - Insertion Sort
- `3_heap_sort.cpp` - Heap Sort
- `4_merge_sort.cpp` - Merge Sort
- `5_quick_sort.cpp` - Quick Sort
- `6_selection_sort.cpp` - Selection Sort

---

## 🚀 How to Run

Compile any C++ program using a modern C++ compiler (`g++` / `clang++` / `MSVC`):

```bash
g++ -O2 graph_algorithms/1_dijkstra.cpp -o dijkstra
./dijkstra
```
